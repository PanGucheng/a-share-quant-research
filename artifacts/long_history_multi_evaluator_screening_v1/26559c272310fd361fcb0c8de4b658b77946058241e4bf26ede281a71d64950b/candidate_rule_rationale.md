# Candidate Rule V0：一次性冻结理由

本规则在 2010–2023 primary evidence snapshot 完整封存后制定；未计算候选名单或据候选个数调节。三个 backend 使用同一个 development 全期 Qlib Rank IC 符号，明确为数据导出方向，不使用历史或近期方向。

首次经验分布：绝对全期 Rank IC 的 25%/50% 分位约为 0.01791/0.03987；年度方向一致率的 10%/50% 分位约为 0.7143/0.9286；加权收益年度一致率的 25%/50% 分位约为 0.6429/0.7857。610 个原始 p 值到达 1/1001 下限，p 值不能再细分其强弱。完整分布与证据哈希由 freeze 绑定。

共享条件：至少 1260 个可评价信号日、至少五个各有 126 日数据的年度，避免把少量样本解释成长历史；|mean Rank IC| >=0.02，使用低于中位数且略高于下四分位的整数量级，排除虽可能显著但平均关联很弱的信号，不设候选配额；至少 70% 合格年度方向一致，要求多数年份延续，允许反向年份；primary BH q<=0.05，BY q 作依赖敏感性标注。

Alphalens：同方向 Q5−Q1 >0，五个全期平均分桶收益与桶序号的同方向 Spearman >=0.8，且至少1260个五分桶有效日，要求明显分层形态，避免仅用正端点差。该 monotonicity 是从已冻结原生分桶输出派生的汇总。

jqfactor：同方向全期 factor_returns >0、至少1260日与五个合格年度，且至少60%合格年度同方向收益。60%表示多数年度支持收益加权视角，弱于全排序 IC 的70%要求，因为权重集中与分布尾部会产生不同敏感性；不要求所有 Era 通过。

Qlib：同方向 Pearson >0 与原生 long-short >0，long-short 至少1260日。它要求线性相关和原生两端信号支持排序方向，不另外选择一个人为不同的 Rank IC 门槛。

零是收益/相关方向的自然界线；本轮不发明费用模型或从结果搜索收益幅度阈值。上述收益都是重叠20D评价标签，不是每日可复利策略收益。

标注只供审阅：年度方向一致率<70%或任一有数据Era反向标 direction_instability；单个Era占绝对IC总和>60%或任一leave-one-era-out方向均值<=0标 regime_concentrated；有效IC样本/canonical成熟信号行<80%标低覆盖；BY q>0.05标敏感性。Era贡献按mean×valid_dates计算，leave-one-era-out按剩余原始日数加权，不作四Era硬AND，不形成加权总分。

必需指标非有限或方向未定义时，该 backend 为 unavailable；不得伪装为 fail/0分。所有可判定 backend 才给出n/3，否则显示incomplete。所有765行及9个blocked inventory均保留，source不享有特权。仅导出各backend pass列表及其并集供人工审阅，不是最终因子池。

限制：首次全期分布已用于定规则，所有结果都是回溯development证据。BH依赖假设与相关因子库存限制其解释；BY仅作敏感性参照。Rank IC的q值不为原生收益/形态条件或最终候选集合提供额外FDR保证。三体系高度相关，3/3不是三次独立确认。库存资格曾使用后期数据；2024+不是全项目未见OOS，本轮未访问。10D、可交易性、费用、微盘暴露、全量数值冗余/聚类均未完成。
