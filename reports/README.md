# Reports

This directory contains compact, human-readable research evidence intended for Git:

- Markdown conclusions and limitations;
- small CSV or JSON summaries;
- necessary small figures and indexes;
- explanations of frozen artifacts or runtime outputs.

Reproducible runtime results belong in `outputs/`, immutable machine objects belong
in `artifacts/`, and disposable cache or scratch data belongs in `tmp/`. Genuine
Forward evidence continues to use its existing append-only paths under
`outputs/forward/`.

Adding a report does not replace the hash, receipt, or immutability contract of a
frozen artifact or Forward prediction.
