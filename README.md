# Qlib Baseline

This project is an isolated baseline runner for the official Qlib A-share LightGBM + Alpha158 workflow.

## Layout

- `configs/workflow_lightgbm_alpha158_csi500.yaml`: qrun workflow config copied from Qlib's official LightGBM + Alpha158 CSI500 example, with only `provider_uri` pointed to the local `cn_data`.
- `scripts/run_baseline.ps1`: reusable runner for `qlib_env`.
- `logs/`: captured qrun logs.
- `outputs/mlruns_validated/`: MLflow experiment records and artifacts generated by qrun.
- `data_quality/`: read-only A-share Qlib data quality diagnostics.
- `outputs/data_quality/`: generated data quality reports and CSV diagnostics.

## Run

```powershell
cd E:\qlib_prj\qlib_baseline
.\scripts\run_baseline.ps1
```

## Data Quality Diagnostics

```powershell
cd E:\qlib_prj\qlib_baseline
.\scripts\run_data_quality.ps1 --config data_quality/config.yaml
```

Override the market or date range:

```powershell
.\scripts\run_data_quality.ps1 --market csi300 --start-time 2020-01-01 --end-time 2020-03-31
```
