# 小资金执行可行性：E2 / E3 前置研究

日期：2026-09-13；基线 `main@447c87a`，fetch 后与 origin/main 一致。
依据用户要求实施《给 Codex：小资金实盘约束下的 E2 - E3 前置研究计划.md》。
附件是研究建议；本文件明确实际方法和边界。E1 已完成，不重跑；E2 BLOCKED，E3/E4 未授权。

## 本轮实施范围

主资金情景改为人民币 50,000 / 100,000 元。原百万级结果保留为工程证据。
只复用已封存 E2 三个全池行情快照：2015-08-28、2020-08-28、2023-08-28及各自之前20日。
不访问 provider，不读预测、label、收益或2024+数值。先验证历史 receipt，再读明确列。
快照成员是该日 sealed keys，未证明盘前可得；因此只作静态机械可行性，不能解释为已执行订单。

运行前固定：K = 3 / 5 / 8 / 12 / 16 / 24 / 32 / 50 / 100 / 200。
每日期采用32个 SHA256(date, replicate, instrument) 排序排列，取前K；各K使用相同排列前缀。
另取紧随其后的K只作为独立换入篮子。没有依价格、行业或分数选股；未知值及已知异常保留原分母。
这些是池内价格暴露样本，不是 B TopK，不是独立随机试验，不能给出时间外置信区间。
完整池另计算每个K预算下的已知价格可建仓比例，避免只靠少量篮子的选样偶然性。

复用 dated_fees、MotherOrderFees、lot_quantity，逐母单组件分币舍入；按用户补充采用佣金万2.5、双向最低5元，印花税/过户费另算；仅覆盖本轮假设，不改旧表。
固定现金预留5%；每名预算为0.95×AUM/K，费用包含在预算中；以上一交易日raw close定量，不以当日open倒推数量。
主板/创业板100股步长，科创板200股起、之后1股；代码前缀仅作数量规则分类，不证明交易权限或历史特殊状态。
不把建不起的股票替换为廉价股票、不把余额重新分配给其他股票、不默默改变K或权重。

诊断输出：已知/未知价格、ADV20、异常单位、可买数量、建仓费、参考证券配置比例、剩余现金、
权重偏差、名义持仓数与按已配置权重计算的有效持仓数、lagged ADV 1%代理、最低手金额分位数。
单日期新建篮子中，open仅作事后现金压力，另给全部买价+10%/+20%的固定情景，不能称历史涨跌停规则或成交证据。
换仓只做独立袖套现金算术：假设原买量在同一参考价全数可卖，扣原买费/卖费后，用回收资金与该袖套余额买入下一只。
不串日期、不生成损益或NAV；卖出完成/T+1、停牌、特殊规则和新股可成交均未被该算术认证。

运行前声明解释尺度（工程偏好，不是统计或投资定理）：K<5意味着名义单名预算超过19%；
已知价格可买比例低于90%、篮子证券配置中位数低于80%、新建费中位数超过AUM的25bps，分别标示价格、现金、佣金压力。
这些尺度用于描述候选区间，不能把通过三点静态样本升级为可实盘或最优K；报告必须并列三个日期，保留未知和分布尾部。
不强求唯一 primary K；缺少真实TopK价格暴露时，允许只建议审议区间。

## 必要的方案更正

percentile宽组合可保留为学术参考；fixed-K更直接表达个人资金的持仓预算。
全池EW在5万/10万元下不能复制，不是原始数据是否就绪的判定标准；应转为独立的基准定义审议项。
未来宽参考若采用分数股/无成本，必须命名为非可交易研究参考，不能与含费用策略混称相同执行账户。
用户可买的宽基基金可作为另一种基准提案，但需要单独冻结标的、历史覆盖、分红和费用，不能本轮自动替换为具体ETF。

用户补充假设科创板/创业板权限均已开通。真实券商费表仍待核实，后续按合同替换，不根据收益调整。
小K的名义分散度不是行业/相关风险分散证明。不得以历史收益或IC补做选择。

## Fixed-K structural check 的最小设计

本轮交付设计和 synthetic 状态机验证；尚无审议后的唯一K，因此不自动运行九年真实预测扫描。
人工审议K后，仅用原B494、2015–2023、该唯一K，比较无buffer TopK和一个 proposed hold cutoff = 2K。
2K只是一条待证候选，不由E1的10/20结论推导为已有效；不做 K×buffer 网格。
每个signal日按 score降序、instrument升序处理并列：保留仍在可用排名且rank≤2K的旧成员；
只从rank≤K的新成员补足至最多K；缺失/离池计独立原因，不因报价缺失在这个prediction-only层过滤。
缓冲状态从首个有效日空集合开始，年度模型切换时不重置；缺完整日期必须报错，2023末只做右删失。
这仅定义目标成员；真实持仓不能因离开signal而自动卖出，须走执行与held-stock continuation。
输出成员退出率、Jaccard、两侧成员增删率、完成持有期/右删失、低于K的天数、保留排名分布、年度切换前后描述；
不把成员换手命名为实际成交金额换手。与独立朴素集合重放逐日核对。
明显病态包括重复成员、超过K、保留rank>2K、补入rank>K、缺日期被跳过、年度重置、未知报价影响排名；
稳定性数值本身只作描述，不根据哪条曲线更好继续搜索。
未来真实扫描若较长，仍由用户运行；本轮不提供尚未批准K的可执行长跑入口。
