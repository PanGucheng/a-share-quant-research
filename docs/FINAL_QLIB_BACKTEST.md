## 执行近似与必要检查

原生Qlib承担选股、交易、账户和报告。两个小型子类仅阻止静默回退和缺失持仓估值，
不重写成交算法或公司行动系统。

| 项目 | 口径 |
|---|---|
| 费用 | 买0.00026、卖0.00076、最低5元，原生合计收费；非逐项券商费用 |
| 滑点 | 买价=open×1.001、卖价=open×0.999；已含在账户收益，不重复扣费 |
| 交易限制 | 开盘相对昨收±9.5%，触限时双向禁止；不使用当日收盘涨跌幅决定开盘交易 |
| 交易单位 | Qlib原生100股，结合factor；factor缺失/非正会报错，不能退化为碎股 |
| 流动性 | 前20日平均量×1%，以Qlib复权量口径限制；不是竞价量证明 |
| 缺失开盘/参考价/均量 | 该证券当日禁止成交，不允许自动改收盘成交 |
| 持仓退出候选范围 | 保留证券持仓和后续行情；不能因不在新分数里而删除 |
| 实际持仓缺失估值 | 中止并保存failure.json的证券/日期；不静默长期沿用旧价 |
| 分红/配股/特殊制度 | 接受现有复权行情；不另建账本，不精确模拟ST、各板块、退市等制度 |

结果为有成本的日级历史模拟，不是实盘成交认证。2024+可能已在项目其他研究中观察过，
不宣称全项目fresh OOS。不同年份表现不触发自动换参。
